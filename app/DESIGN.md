# 今晚这一页 · 设计说明

工作标题「今晚这一页」。一台手机，两人共用一本手帐。题库原文仍来自 `app/data/raw.json`，不改写。

视觉：暖色素纸、墨色字、珊瑚红、浅黄胶带、枯绿。贴纸略微倾斜，撕掉留胶痕，印章有按压。不要暗紫、金色极光、夜航皮肤。

## 一晚怎么走

封面（称呼、尺度、边界）→ 热身 6 格 → 贴纸店 → 升温 6 格 → 贴纸店 → 靠近 6 格 → 封底海报。

每一格只占一个贴纸位。自选贴和对贴按贴纸回合交替，对贴的两张落在同一格。特殊格占用其中一格：

| 页 | 槽位 | 游戏 |
|---|---|---|
| 热身 | 第 3 格 | 今晚的温度贴 |
| 升温 | 第 2、5 格 | 真心话贴纸轮、大冒险印章轮 |
| 靠近 | 第 4 格 | 手帐地图贴 |

## 规则

- **自选贴**：领航员从 3 张里挑 1 张递给对方。对方贴上（可写一句短注）或撕掉。
- **对贴**：两人各看自己的 3 张，先后扣下再揭晓。可以只撕其中一张。两张都贴上、而且同类型或星级差不超过 1，对页印 +1。
- **叠贴**：每贴上 3 次出现一次，或用贴纸店的「多一次叠贴」。不是惩罚，也可以不叠。
- **撕掉**：留下胶痕，不扣升温、不扣胶带、不卡关。
- **升温**：星级 1–2 记 1，3 记 2，4 及以上记 3。温度贴另算，最近 +3，最远 +1。
- **胶带段**：开局 3。每次成功贴上 +1。贴纸轮重拨 −1，最多 2 次。
- **贴纸店**：再看一张 2、降一档尺度 2、多一次叠贴 3。可以不买直接翻页。
- **尺度**：温柔 / 暧昧 / 热烈 / 不设限，加上黑名单和柔和模式，抽贴纸时过滤。
- **安全词**：页角「合上本子」，长按约 1.5 秒。已贴上的保留，不扣不评。
- **封底印章优先级**：合上本子 → 撕掉 ≥6 → 升温 ≥32 → 对页印 ≥3 → 温柔合上。

四款小游戏可以从游戏厅单独打开。单独玩完的结果可以贴进今晚的页边；还没翻开手帐时，先夹在本机，下一本会贴上。
