# 升温夜航 3D · 纵切原型

这是 3D 版的第一步：验证“3D 棋盘 + 真心话大冒险翻卡”的手感，不替换现有 2D 版。

## 现在有什么

- 一张 80 格蜿蜒夜航公路（起航 → 灯塔）
- 一男一女两枚棋子，轮流摇骰；每个格子悬浮项目标签
- 3D 骰子：翻滚、落桌、回弹，逻辑点数与动画分离
- 落格翻卡：真心话 / 大冒险 / 事件 / 对撞 / 安全屋
- 温度槽、回合切换、抵达灯塔结算
- 手机竖屏 390×844 设计，镜头跟随当前棋子，DOM 卡牌 + WebGL 场景

## 开发 / 构建

```bash
cd app3d
npm install
npm run dev      # 本地开发
npm run build    # 输出到 ../3d/
```

构建产物提交在仓库根目录 `3d/`，由 GitHub Pages 直接托管：

`https://chundongtou.github.io/couple-game/3d/`

## 技术

- Three.js + Vite
- 场景：低多边形玻璃桌、星海、12 格环岛、两枚棋子、3D 骰子
- 文字/按钮全部走 DOM 覆盖层，3D 只负责氛围和棋子
- 骰子逻辑随机与动画解耦，后期可替换为服务端/种子随机
