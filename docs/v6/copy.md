## 0. 使用说明（FE 先读这 4 条）

### 0.1 占位符

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{name}` | 当事人姓名（开局填的名字，默认「他 / 她」） | 阿岚 |
| `{a}` / `{b}` | 两位玩家的姓名 | 阿岚 / 小满 |
| `{n}` | 序号或计数（题卡张数、格号、架号） | 3 |
| `{planes}` | 每人飞机数（快局 2 / 长夜 4） | 2 |
| `{home}` | 某一方已到家架数（0–`{planes}`） | 1 |
| `{cards}` | 本局已处理题卡数（V6.1 起只是过程计数，**没有目标值**） | 6 |
| `{round}` | 第几回合（引擎 `round` 计数） | 4 |
| `{flying}` | 当前在棋盘上的飞机数（机坪外、未到家） | 1 |
| `{heart}` | 心动值 0–100 | 24 |
| `{streak}` | 连击数 | 2 |
| `{time}` | 时长，`mm:ss`；超过 1 小时用 `h:mm:ss` | 42:15 |
| `{scale}` | 尺度名（温柔/暧昧/热烈/不设限） | 暧昧 |
| `{x}` | 百分比（整数） | 68 |
| `{m}` / `{d}` | 月 / 日 | 10 / 25 |
| `{color}` | 颜色名（红/黄/蓝/绿） | 红 |
| `{grid}` | 格名（§2.6 的 13 种之一） | 真心话格 |
| `{k}` | 回家航线第几格（1–5） | 3 |
| `{v}` | 版本号 | 6.1.0 |

### 0.2 排版与语气规范

1. 中文标点：用「，」「。」「、」「：」「？」；引号用「」；省略号用 `…`；**句末不用感叹号**（确认类弹窗也不加）。
2. 数字用阿拉伯数字；量词固定：题卡「张」、掷骰「点」、小游戏「次」、飞机「架」、格子「格」。
3. 状态条用 `·` 分隔，`·` 两侧各一个半角空格：`红 1/2 · 黄 0/2 · 心动值 24 · 连击 2`（V6.1 起状态条读「双方已到家」，不再有「第 N/目标 张」）。
4. 按钮文案 2–6 字，动词开头；同一动作全站同一个词（见 §0.4）。
5. 句子短、语气轻、不用命令句；不吓人、不催、不评判。
6. 不写「必须 / 应该 / 一定要 / 最后机会」；不写题面、不写具体动作。
7. 空状态也要温和地承认这一晚：见 §6.3。
8. 文案里出现的**计数与数值**必须来自状态，不允许写死。

### 0.3 禁用词（只作检查清单，不用于任何界面）

以下词**不得出现在任何界面**：失败、惩罚、扣分、输了、赢了、输赢、淘汰、扣、惩罚卡、必须做、不做就、最后机会、未成年、以及 `app/src/engine/flight-draw.js` 的 `EXPLICIT_SRC` / `GENTLE_EXTRA_SRC` 命中的所有词。

替代说法：
- 「失败/扣分」→「先放过」「先不选」「这次先跳过」
- 「输了/赢了」→「今晚完成了」「一起走到这里」
- 「必须」→「可以」「要不要」
