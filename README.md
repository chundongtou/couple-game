# 今晚飞行棋 V8.2.2

两个人，一部手机，一盘飞行棋。夜航客舱里，小桌板上一盘棋；舱灯调暗，摇骰子、抽题卡，玩到今晚收尾。快局约 15–25 分钟，长夜约 30–50 分钟。V8.2 起，主桌默认就是**真 3D**：设备能跑 WebGL2 就进 3D 桌面，飞行时**飞机固定在屏幕中心、棋盘旋转平移**，落到题卡格后 45° 格子升起、3D 小熊探头；跑不动、加载失败或手动关掉时，自动回到 V7 的云海机舱与镜头链。

谁先把自己这一局的飞机全部送回家，谁就「先到家」：快局每人 2 架、长夜每人 4 架；之后两张收尾卡一人一张。只写「先到家」，不写输赢；做过的都留着，任何一屏都能「先收棋」。

- 线上：<https://chundongtou.github.io/couple-game/>
- 版本：**8.2.2**（`app/src/app.js` 的 `App.version`）
- 形态：纯前端单页 + PWA；没有后端、没有账号，数据只在这台手机的 `localStorage`

## 3D 主桌（默认，V8.2）

V8.2 起，进主桌时**默认先试 3D**：手机 / 浏览器能跑 WebGL2 就用 3D 主桌；不能跑、3D 资源没拿到、挂载失败，或你手动在设置里选了「V7」，就回到 V7 的云海机舱主桌——**两种主桌都能完整玩完一局**，规则、题库、存档、边界与安全词完全一致。

| 设置里的「3D 主桌」 | 行为 |
|---|---|
| `auto`（默认） | WebGL2 可用就进 3D；**开了「减少动画」仍是静态 3D**（不转镜头）；WebGL2 不可用 → V7 |
| `off`（V7） | 始终用 V7 云海机舱 + 镜头链 |
| `on`（3D） | 强制尝试 3D；WebGL2 不可用 / 资源失败 / 挂载失败仍会自动回 V7 |

- 3D 资源是**独立的懒加载 chunk**（`assets/board3d.<hash>.js`，构建时注入 `window.__BOARD3D_URL`，首屏没有 `<script src>`）；只在进主桌且开关/能力允许时才下载一次，失败不重试、不阻塞棋局。
- 进 3D 时会有轻提示：「正在载入 3D 主桌…」→「3D 主桌已开启 · 飞机将固定在屏幕中心飞行」；回 V7 时提示「3D 主桌这次没起来，先用 2D 桌面」，WebGL2 不可用时提示原因。
- 降级是**完整的 V7**：机舱场景、SVG 棋盘、Cinema 镜头链、45° 格子舞台、小熊、题卡全部照旧；不会白屏、不会卡在载入。

### 3D 飞行与镜头链

3D 主桌的每回合是：**俯瞰 → 掷骰 → 对准飞机 → 飞行 → 落地 → 45° 格子 → 小熊 → 回俯瞰**。

| # | 阶段（`data-3d-phase`） | 画面 | 大致时长 |
|---|---|---|---|
| 1 | `idle` | 3D 棋盘俯瞰，棋盘约占主桌宽 87%、垂直居中；当前玩家一侧更亮 | 常驻 |
| 2 | `roll` | 3D 骰子抛落、停在引擎点数（六面按 `DIE_FACES` 映射到 BoxGeometry）；镜头轻推近骰子 | 约 0.6s + 骰子落定 |
| 3 | `focus` | 镜头对准要动的那架飞机（起飞从机坪、走子从当前格） | 约 0.95s |
| 4 | `fly` | **飞机钉在屏幕中心不动，棋盘旋转 + 平移**，把目标格送到机腹下方；逐格前进（每格约 165ms，进航线约 190ms；起飞 900ms；跳 540ms / 飞 840ms），飞行中格面中文暂时隐去、只留色块与图标 | 按步数 |
| 5 | `land` | 目标格光晕/涟漪、轻震，镜头拉到落点 | 约 0.46s |
| 6 | `cell45` | 棋盘压暗，目标格升起 1.5 个世界单位到 45° 舞台（24° 方位） | 约 0.9s |
| 7 | `bear` | 3D 小熊从格子左后探身（不压格面字），右侧滑入 **DOM 题卡**；等你「做了 / 放过」 | 小熊约 0.56s |
| 8 | `return` | 卡片收起、小熊退场，镜头拉回俯瞰 | 约 0.7s |

- **飞行错觉的关键**：fly 期间相机停在 focus 结束时的位姿（不再移动），飞机固定在世界原点上方（屏幕中心）；变化的是棋盘组的旋转角与平移，飞机本身不移动。这样计算便宜、画面稳，也方便在窄屏上始终把目标格放在机腹下方。
- **骰面与引擎一致**：`BoxGeometry` 的材质顺序是 **+X / -X / +Y / -Y / +Z / -Z**，3D 骰子按 `DIE_FACES = [3, 4, 1, 6, 2, 5]` 取贴图（`dieFaceNormal / dieSettleQuat` 也按同一映射求法线），所以 HUD 写「掷出 N」时 3D 骰子停在 N 点（V8.2.2 修复了之前的错面）。
- 3D 里题卡**只出右侧的 DOM 内容卡**（`.v6-table.v8-3d-card`）：左列 45° 舞台隐藏（`.cs-left{display:none}`），左侧留给 3D 格子与小熊；卡片仍可点、可滚、长文不裁切。
- 做了 / 放过后，3D 会回俯瞰再继续（`returnToOverview`），不会把 3D 拆掉；题卡打开期间 3D 停在 `bear` 等你。
- **减少动画**：3D 直接给静态棋盘（不转镜头、无速度线、无震动，骰子与走子落终态）；`auto` 下也不会因此回 V7。
- **3D 视角不是自由视角**：只有导演镜头，不能用手指旋转 / 缩放 / 转头；也不能点 3D 棋盘选子（选子仍走 HUD 与文字按钮）。

### 3D 图例与设备自检（V8.2）

- 3D 模式 HUD 里有「图例」按钮：打开是一张 11 行的格子说明（`真 / 敢 / 触 / 缘 / 温 / 轮 / 起 / 飞 / 停 / 归 / ·`），和 3D 格面短字一一对应；面板挂在棋盘区、顶边永远在 HUD 之下，**不遮暂停与安全词**；打开时底部行动区先收起，320×568 也能一屏读完；题卡上来或 3D 回落时自动收起。V7 不显示这个按钮（V7 的「落点格名 → 格子说明」原样保留）。
- 设置页「3D 主桌」三档下面有一行**设备自检**（只读，不改设置）：「当前设备：3D 可用 · 自动 · WebGL2 可用 · 减少动画：关 · 上次进主桌：用上了 3D / 用了 V7（原因）/ 还没进过主桌」。如果浏览器没开 WebGL2，会直接写「当前浏览器未开启 WebGL2，会使用 V7」。
- 自检同时带机读属性 `data-webgl2 / data-reduced / data-board3d-set / data-board3d-mount / data-board3d-reason`，方便排查「为什么没进 3D」。

### 3D 的边界（明确没做）

- **没有 3D 机舱全景**：3D 场景是「机舱里的一张 3D 小桌板 + 云海 / 星轨 / 纸雕背景」，不是可环顾的 3D 客舱。
- **题卡文字仍是 DOM**：3D 只负责棋盘、飞机、骰子、格子与小熊；可读文字（题卡、HUD、安全词、暂停）始终是 DOM，保证可读性、无障碍与长文本。
- **小游戏仍是原来的面板**：落在温度计 / 转盘格照旧打开 DOM 小游戏，不进入 3D 场景。
- **真机 3D 帧率 / 发热未验**：本文不写手机 fps；3D 在无头软件光栅环境下的帧率不代表真机，验收只记录几何量与 JS 更新耗时。
- 3D 资源体积、构建门与验收数字见 [`docs/v6/release-notes.md`](docs/v6/release-notes.md) 与 `reports/v6/`。

## 场景与镜头：云海机舱（V6.2 起，V7 换导演）

主桌不再是一块漂在夜空里的棋盘，而是「夜航客舱里、小桌板上的一盘棋」。场景只做背景和氛围，不比棋盘和按钮高一层，也不抢点击：

| 层 | 内容 | 说明 |
|---|---|---|
| 舱壁 | 深靛 / 酒红舱壁、竖向壁板接缝、顶部行李舱弧线 | 静态 CSS，带极轻噪点与暗角 |
| 舷窗 ×2 | 圆角窗框、遮光板、玻璃反光；窗外夜空 | Canvas 画云、星星、月/晨光、机翼与机翼灯；热度与收家时从夜航过渡到晨光 |
| 小桌板 | 浅木色桌板 + 垫布 + 边缘高光与投影 | 棋盘精确落在垫布上；不改变 52 格布局与点击 |
| 光效 | 阅读灯呼吸、换手侧灯、题卡聚光、击落闪白、热度暖光、收家顶灯 | 用 CSS 变量与透明度变化，不遮 UI |
| 前景 | 灰尘 / 星尘、暗角、玻璃反光、颗粒 | `pointer-events:none`；reduced 时粒子减半或静止 |

V7 起，镜头分成两层（都只改画面，不动布局、不拦点击）：

- **`App.Cinema`（V7）**：独占棋盘的 `transform`，按每回合的镜头链驱动推拉、俯仰、POV 前景与跟拍；语义见下一节。
- **`App.CabinScene`（V6.2，保留）**：退到场景层做舱壁 / 舷窗 / 小桌板 / 阅读灯的视差与明暗，以及击落闪白、换手侧灯、热度暖光、收家日出这些光效；不再写棋盘的 `transform`。
- **减少动画**：设置里的「减少动画」或系统 `prefers-reduced-motion` 会关掉镜头移动、震动、闪白、波纹与粒子浮动（粒子减半或静止）；V7 还会跳过 POV 与跟拍，只留 120–200ms 淡入。对局、掷骰、题卡与安全词流程完全不受影响。
- **性能**：镜头全部走 `transform` / `opacity`，只在过渡期间跑一条 `rAF`，结束即释放；场景 Canvas 的 DPR 有上限、空闲约 30fps、页面切到后台暂停。首屏体积预算不变，实际数字以 QA 报告为准。
- **降级**：Cinema 或机舱场景缺失、挂载失败时，主桌回退到 V6.2 的机舱镜头或暗色底照常玩；表现层出错不会中断棋局。

## 每回合怎么走（V7 镜头链 · 3D 不可用时）

V8.2 的主桌默认走上面的 3D 镜头链；只有回到 V7（设置选 V7、无 WebGL2、3D 资源失败或挂载失败）时，才走这一节的老镜头链。V7 把一回合拆成一小段电影：先给全景，再坐进驾驶舱，然后跟到落点，最后把目标格升起来讲这一格。

| # | 状态（`data-cinema-state`） | 画面 | 时长 |
|---|---|---|---|
| 1 | `overview` | 整个棋盘俯瞰；当前玩家一侧灯亮 | 常驻 |
| 2 | `roll` | 骰子落桌、镜头轻推近、机舱跟着轻震一下 | 约 1.0s |
| 3 | `overview`（多子可走时停在这里） | 回到俯瞰，可走子高亮 + 文字按钮，等你选子 | 用户操作 |
| 4 | `pov` | 第一人称短镜头：机头 / 机翼 / 速度线，云从两侧掠过，棋盘在下方倾斜 | 约 1.1s |
| 5 | `chase` | 第三人称跟拍：沿航线跟到目标格，目标格发光，飞机由远到近 | 1.5–2.3s（按步数） |
| 6 | `land` | 落地：尘土 / 涟漪 / 轻震，目标格放大 | 约 0.5s |
| 7 | `cell45` | 棋盘压暗，目标格升到 45° 格子舞台 | 打开舞台即进入 |
| 8 | `bear` | 小熊从格子后探头，右侧滑入内容卡 | 舞台打开后约 0.64s |
| 9 | `return` | 选「做了 / 放过」后卡片收起，小熊挥手，镜头拉回俯瞰 | 约 0.8s |

- 整条镜头链目标 **5–8 秒**（不含答题和读卡时间）；选了「做了 / 放过」之后才回俯瞰。
- 只有「多子可走」时会在 `choose` 停下来等你；其它情况自动走。
- 动画中会出现「快进」小按钮：点一下直接到这一段终态，后面的镜头也不再等动画；不影响棋局结果。
- 开「减少动画」时：跳过 POV 和跟拍（只留 120–200ms 淡入），不做震动，格子舞台静态出现。
- POV 是固定机位的前景镜头（机头 / 机翼 / 速度线），不是可以转头环顾的自由视角。

门厅在「摆上棋盘」之前多了一排「今晚的桌面」，三选一，点一下立即换、立即记住（V8 的 3D 主桌也跟随这组主题：垫面 / 盘面 / 中心终点 / 小熊服装按主题换材质）：

| 桌面 | 名字 | 观感 | 小熊 |
|---|---|---|---|
| `cloud`（默认） | 云海机舱 | 云海冷蓝 + 暖阅读灯；内容卡暖纸 | 机长小熊（帽子 / 围巾 / 护目镜） |
| `star` | 星轨夜航 | 深紫星空 + 金色星轨；内容卡紫纸 | 星轨小熊（披风 / 星星别针） |

### 45° 格子舞台

这是 V7 主桌（3D 不可用 / 手动选 V7）的呈现；3D 主桌里对应的是 3D 格子升起 + 小熊 + 右侧 DOM 卡（见上面的「3D 主桌」）。两种情况下，落在题卡 / 命运 / 收尾 / 进航时，棋盘都会压暗、目标格升起：

- **430 宽**：左侧约 28% 是 45° 格子和探头的小熊；右侧约 68% 是内容卡（类型 / 星级 / 归属 / 来源 + 做了 / 放过）。**320 宽**：左边收到约 22%，内容卡约 74% 可滚动，按钮固定在底部。
- 格子场景按主题换材质：云海是云纹、星轨是星图、纸雕是纸层；内容卡文字始终正向，不做透视。
- 变体：普通题卡、命运格二选一（另加「今晚先不选」）、收尾信、进航题卡；小游戏格仍直接打开原来的小游戏面板，不经过 45° 舞台（见「已知限制」）。
- 长文本在卡片内部滚动，按钮固定；也可以「先看棋盘」暂时收起舞台，再「回到这张」。
- 安全词与暂停永远在舞台之上；舞台不吃棋盘点击。

## 玩法（就是游戏里的「玩法速览」六条）

1. **6 起飞 · 6 可再掷**：掷出 6，才有一架飞机从机坪起飞，走完还能再掷一次；连续两次自己的回合都没掷出 6，第三次任意点数保底起飞。
2. **跳 / 飞 / 进航**：落在跳格向前 4 格，飞点向前 12 格；进航格转进自己的航线。
3. **击落回机坪**：落在对方飞机所在的格子，对方的飞机回机坪。
4. **先到家就收尾**：一方把本局全部飞机送进终点就收尾——快局每人 2 架、长夜每人 4 架；题卡数与心动值只作过程记录。
5. **放过不惩罚**：题卡可以放过——心动值不减少、不挡路、连击不清零。
6. **安全词随时可停**：按住右上角「先收棋」1.6 秒，任何屏幕都能先停一下。

目标：**快局** 每人 2 架，谁先把自己 2 架送进终点谁「先到家」（约 15–25 分钟）；**长夜** 每人 4 架，先送完 4 架（约 30–50 分钟）。之后两张收尾卡一人一张；题卡数与心动值不再决定何时结束。

## 尺度与边界

| 尺度 | 星级上限 | 这一档的口径 |
|---|---|---|
| 温柔 | ★1 | 只留 1 星；排除露骨句，以及束缚 / 露出 / 道具 / 蒙眼 |
| 暧昧 | ★1–2（最多到 3） | 偏向 2 星；露骨句仍排除 |
| 热烈 | ★1–3（最多到 5） | 偏好 3 星起，开放更直接的句子 |
| 不设限 | ★1–4（最多到 5） | 偏好 4 星起；`spark` 池只在这一档开放 |

- 边界在开局、暂停页、设置里都能加；**任何尺度都会排除**写着边界的卡（标签或自定义词）。
- **安全词不是结束**：暂停只是先停一下，记录一条不少；只有暂停页的「今晚就到这」会把这一局归档并进回顾。
- 全部内容面向成年伴侣，需要双方在场、共同同意；任何一方随时可以停。不是给未成年人的内容。

## 已知限制

- 只做竖屏，目标宽度 320–430；横屏 / 平板不做两栏布局。
- 两个人共用一部手机、轮流操作；没有联机、没有账号、没有云同步、没有第三人。
- 依赖现代浏览器（SVG / `backdrop-filter` / Service Worker）；很旧的 WebView 会降级，动画自动变短。
- 安装到主屏幕需要 `https` 或 `localhost`；用局域网 `http://IP` 打开时只能玩，不能安装。iOS 需要 Safari「添加到主屏幕」。
- 设置里的 `boardView:"3d"` 是 V5/V6 的旧预留字段，V8 起不起作用；3D 主桌用新的 `settings.board3d`（`auto` / `off` / `on`）。
- **3D 主桌的资源与边界**：3D 是独立懒加载 chunk（当前发布构建里 `assets/board3d.48364fb6.js`，155.06 KiB gzip，验收 ≤160 KiB；冻结单 140 KiB 目标在 three r180 下不可达，记为已知偏离），首屏不加载它；断网时靠 SW 预缓存。真机 3D 的 fps / 发热 / 耗电**未验**，本文不写手机 fps。
- **3D 没有机舱全景、没有自由视角**：3D 场景是「机舱小桌板 + 云海 / 星轨 / 纸雕背景」，镜头只有导演镜头（不能转头 / 环顾 / 手势旋转 / 捏合缩放）；选子仍走 HUD 与文字按钮，不能点 3D 棋盘选子。
- **3D 题卡文字仍是 DOM**：3D 只负责棋盘、飞机、骰子、格子与小熊；题卡、HUD、安全词、暂停都是 DOM，3D 不承载可读文本。飞行中格面中文会暂时隐去（避免旋转斜置），落地 / 题卡时恢复。
- **3D 小游戏仍是原面板**：落在温度计 / 转盘格照旧开 DOM 小游戏，不进入 3D 场景。
- **320 宽下图例可读、格面短字仍偏小**：3D 格面短字在 320 视口约 20px，V8.2 用 HUD「图例」补齐语义；若仍看不清，可切回 V7 或用更大的屏。
- **3D 中途 WebGL context lost 未验**：已验证的降级是「无 WebGL2 / chunk 404 / 挂载返回 null / 挂载抛错 / 手动 off」五条；进 3D 后 GPU 上下文丢失的回退未覆盖。
- **3D 音效未做真机混音校准**：音效是 WebAudio 合成占位，无头环境只验证代码路径，实际出声待真机验证。
- 机舱场景是**纯背景/氛围层**（`pointer-events:none`，`aria-hidden`），不承载任何玩法状态；所有可点内容仍在棋盘与 UI 层，关掉场景不影响对局。
- 「减少动画」开启（或系统 `prefers-reduced-motion`）时，镜头移动、震动、闪白、波纹与粒子浮动都会关闭，只保留静态场景与淡淡的光色变化；V7 的 POV 与跟拍也会跳过；V8 的 3D 则给静态 3D（不转镜头、无速度线/震动）。
- 舷窗高度受主桌 UI 与棋盘位置的限制：小屏（如 320×640）上会被压矮，不是固定比例；这是为让出棋盘和按钮空间的取舍。
- **POV 不是自由视角**：它是一段固定机位的前景镜头（机头 / 机翼 / 速度线 + 棋盘倾斜），不能转头、不能环顾，也不改变棋盘的可点区域。
- **小游戏还没进 45° 格子舞台**：落在温度计 / 转盘格时仍直接打开原来的小游戏面板；格子舞台的「开始小游戏」变体已写好，但主桌还没接线。
- **格子序号不一定显示**：内容卡能读「来自 真心话格」，但「第 N 格」只在引擎带上格位信息（如进航）时才出现；普通题卡不保证有序号。
- **主题目前不会给主桌机舱整体换肤**：主题改变门厅 / 设置 / 回顾的星空与纸感、文字与按钮色泽、45° 舞台与内容卡材质、小熊服装与 POV 前景；主桌的舱壁 / 舷窗 / 小桌板仍是 V6.2 云海机舱的固定配色（主桌里变化最明显的是 UI 文字 / 按钮、格子舞台和小熊）。
- **45° 舞台是 CSS 3D 透视**：用 `perspective` + `rotateX/rotateZ` 做的立体块面，不是真 3D 引擎；小屏上格子和卡片的比例会按 22% / 74% 收紧。
- `build_app.py --check` 面向干净输出目录。仓库根保留的 V5 `assets/board.js` 是回滚资源，会让「产物不含/不引用 board.js」这一项在仓库根上变红——发布门请对 `dist/rebuild`（或其它干净目录）跑。
