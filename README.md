# 今晚在这间公寓

两个人，一部手机，一枚「我们」。没有抽三张选一张，也没有往格子里贴东西。你们在夜里的公寓里一间间走，灯会跟着热起来。

- 门厅：大衣上的名字、壁灯上的尺度（温柔 / 暧昧 / 热烈 / 不设限）、桌上纸条里的边界
- 平面图：客厅、厨房、阳台、浴室、卧室。去过的房间一直亮着，可以再走进去。卧室从一开始就开着
- 每间房的玩法不一样：沙发上的话、厨房转盘、阳台温度、浴室真话、卧室里更近的话或动作
- 右上角按住「先回去关灯」：已经发生的都留着，不扣、不评判
- 关灯之后是一页「今晚在这间公寓」
- 游戏门里的温度、真话、动作、走一走可以单独玩，也可以带回今晚

题库沿用原来的 1423 条。温柔档会滤掉露骨句；热烈和不设限会更快抽到更直接的句子。纸条上划掉的边界，任何尺度都不会出现。

## 本地

```bash
python tools/rebuild/build_app.py --out dist/rebuild
python tools/rebuild/dev_app.py --port 8877 --out dist/rebuild --no-build
```

浏览器打开 http://127.0.0.1:8877/

生产构建（写出仓库根的 `index.html`，给 GitHub Pages 用）：

```bash
python tools/rebuild/build_app.py --release
```

## 数据

只存在这台手机的 `localStorage`（`couple2.*`）。设置里可以清除。以前的夜可以导出、导入。进行中的旧版「升温夜航」不会在公寓里续玩，会收进以前的夜。
